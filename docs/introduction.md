# Welcome to <p style="color: #FF5F1F; font-size: 50px">UltraChess</p>

<br>

Ultra Chess is a version of chess that allows pieces to combine with each other to create higher ranked pieces. In UC, it is not uncommon to have 3 rooks and 2 queens at any point of time.

For example, if a **bishop** (Lvl 2, Value 3) combines with a **pawn** (Lvl 1, Value 1), then those pieces will create a **rook** (Lvl 3, Value 5). These 2 pieces will now move together on the same square, but with rook capabilities. You will learn more about how each piece combines on the following pages through detailed descriptions and examples.

**Disclaimer:** Ultra Chess is just a variation of chess, with all original chess still applying during play unless stated otherwise (e.g. Checking, Mating, Castleing, etc.)

## Pieces

* **[Pawns](/pawns)** = Level 1 (Value 1)
* **[Knights/Bishops](/knights-bishops)** = Level 2 (Value 3)
* **[Rooks](/rooks)** = Level 3 (Value 5)
* **[Queens](/queens)** = Level 4 (Value 9)
* **[Ultra Queens](/ultraqueens)** = Level 5 (Value 15)
